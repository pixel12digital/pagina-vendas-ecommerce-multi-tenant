# Landing Page - Implantação de E-commerce

Landing page otimizada para conversão, desenvolvida para campanhas de Google Ads focadas em implantação de e-commerce sob medida.

## 🎯 Objetivo

Converter visitantes de campanhas de pesquisa do Google Ads em leads qualificados para serviços de implantação de loja virtual.

- implantação de e-commerce

## 📈 Eventos Customizados

Eventos rastreados via dataLayer:

- `whatsapp_header_click` - Clique no botão WhatsApp do header
- `whatsapp_footer_click` - Clique no botão WhatsApp do footer
- `whatsapp_lead_submit` - Clique no CTA principal (conversão)
- `scroll_depth` - Profundidade de rolagem (25%, 50%, 75%, 100%)
- `page_performance` - Tempo de carregamento da página
